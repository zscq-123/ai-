# Image 2.5 icon assets

The canonical generated PNG files live in `public/brand/icons/image2.5`.
Applications copy the `96` and `256` variants into their own public directories.
Use the paths exported by `@commerce/icon-assets`; do not replace them with SVG.

The storefront set uses a consistent red-and-white rounded 3D retail style with
transparent backgrounds. It is original artwork inspired by large-marketplace
visual language and must not include third-party logos, mascots, or wordmarks.
