# FAQ 知识库导入说明

## 使用流程

1. 客服主管整理常见问题、标准回答和检索关键词。
2. 在运营管理台进入“AI 客服”，上传 JSON、JSONL 或 CSV 文件。
3. 新导入内容处于“待审核”状态，不会立即影响线上回答。
4. 运营负责人检查内容后点击“发布上线”。
5. 已发布问题会显示在商城客服的“常见 F&A”卡片中；客户点击后，AI 使用已发布答案和其他可靠知识作答。

当前管理接口由管理员权限保护。导入和发布已经分成两个操作，但“客服主管”和“运营负责人”的独立账号角色仍需接入企业身份系统后配置。

## CSV 格式

表头必须包含：

```csv
question,answer,keywords
```

`keywords` 使用 `|`、中文逗号或英文逗号分隔。可直接使用
[FAQ知识库导入模板.csv](templates/FAQ知识库导入模板.csv)。

## JSON 格式

```json
{
  "entries": [
    {
      "question": "多久发货？",
      "answer": "现货商品通常在付款后 24 小时内出库，实际以订单物流节点为准。",
      "keywords": ["发货", "出库", "多久发货"],
      "displayOrder": 10
    }
  ]
}
```

也可以直接上传数组，或使用每行一个 JSON 对象的 `.jsonl` 文件。

## 限制

- 单次最多导入 200 条。
- 问题最多 240 个字符，回答最多 4,000 个字符。
- 每条最多 20 个关键词，每个关键词最多 40 个字符。
- 上传同名问题会生成新的待审核版本；发布前不会出现在客户侧。
- 商品实时价格、库存和订单状态仍应来自电商后台或 ERP，不应作为静态 FAQ 上传。
