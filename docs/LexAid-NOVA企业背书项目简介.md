# LexAid × NOVA 企业智能客服项目简介

## 一句话介绍

LexAid × NOVA 是一套面向企业客户服务场景的软硬件一体化 AI 服务方案：NOVA 负责连接企业知识、商品、订单和售后流程，LexAid 智能终端负责将同一套 AI 客服能力延伸到线下现场。

## 项目定位

LexAid 是项目与产品总名称，NOVA 是其中的云端业务与 AI 客服平台。

项目不只是一个回答问题的聊天机器人，而是希望让 AI 在权限受控、数据可追溯的前提下，理解客户需求、调用企业业务工具、核对真实数据，再给出有依据的回复或服务引导。

## 项目希望解决的问题

企业客服通常面临重复咨询多、响应不及时、不同人员话术不一致、业务数据分散、培训成本高等问题。传统问答机器人又容易出现答非所问、信息过期和无依据承诺。

本项目希望通过“企业知识库 + 真实业务数据 + 受控工具调用 + 人工接管”，提高客服的响应效率、答复一致性和服务可追溯性，同时保留企业对高风险业务的决策权。

## 软硬件联动方式

| 组成 | 主要作用 |
| --- | --- |
| NOVA AI 客服 | 理解问题、多轮对话、知识检索、业务工具选择和回复生成 |
| NOVA 业务平台 | 管理商品、店铺、客户、订单、售后和权限数据 |
| NOVA Agent Lab | 独立测试多轮对话、工具调用过程、返回结果和风险门禁 |
| 智能终端 | 通过语音、屏幕、触控和 NFC 等方式，为线下场景提供现场服务入口 |

用户可以通过网页、移动端或 LexAid 终端提出商品、订单和售后问题。AI 客服根据用户身份和当前业务场景，查询经授权的企业数据。需要进一步业务处理时，系统可生成草稿或操作建议，交由客户确认或企业人员审批；涉及投诉、高风险操作或 AI 无法准确判断时，及时转由人工处理。

## 核心能力

- **企业知识问答**：基于企业话术、商品资料和服务政策回答，减少无依据生成。
- **商品咨询与导购**：根据用户需求、预算和使用场景推荐、比较商品，并核对商品状态。
- **订单与物流查询**：在登录与权限校验后，查询客户自己的订单信息，不依靠模型猜测。
- **售后引导**：说明退款、退货、换货等规则，并可生成待客户确认的申请草稿。
- **人工接管**：识别投诉、负面情绪、紧急问题和低置信度回答，将对话与处理摘要交给人工。
- **权限与数据隔离**：不同客户、企业/店铺和测试场景使用独立的数据与会话范围。
- **可测试与可审计**：记录知识来源、工具调用和返回结果，便于企业验收、复盘和质检。

## 企业应用价值

1. 用 AI 承接高频、重复的咨询，让人工聚焦于复杂问题和关键客户。
2. 统一商品、订单和售后口径，降低错答、过度承诺和服务标准不一致的风险。
3. 延伸服务时间和服务入口，打通线上咨询与线下现场服务。
4. 通过对话、工具和处理结果留痕，为客服质检、知识优化和经营分析提供数据依据。
5. 在不取代企业审批与人工责任的前提下，提高服务流程的自动化程度。

## 当前阶段

项目已形成可演示和继续验证的软件原型，包含商城业务平台、AI 客服服务和独立的 Agent 能力测试端；已围绕知识问答、商品咨询、订单权限查询、多轮对话和人工接管进行阶段性验证。
