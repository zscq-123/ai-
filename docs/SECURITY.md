# 安全基线

- 身份统一使用 OIDC；后台写接口要求角色权限，公开接口只开放商品查询、商家申请和经过验签的支付回调。
- 密钥仅通过部署环境注入；仓库、镜像层、日志和前端产物不得包含私钥、支付凭证或完整令牌。
- 支付回调必须验签、幂等和留存审计；退款、取消、改价必须二次确认。
- 服务使用非 root 用户运行；生产入口启用 HTTPS、请求体上限、速率限制、WAF 和来源白名单。
- `/actuator/prometheus` 与 AI `/metrics` 只允许监控网络访问，不通过公网入口暴露。
- 依赖扫描、镜像扫描和密钥扫描应作为受保护分支检查；高危问题未关闭不得发布。
- 日志对手机号、地址、令牌和支付字段脱敏，并设置最小必要的留存周期。

威胁重点包括越权读取跨用户订单、商家跨店访问、库存重放、支付回调伪造、提示注入导致工具越权和知识库数据污染。对应控制分别落在资源级鉴权、店铺归属过滤、幂等键、签名校验、AI 工具白名单与知识版本审核。
