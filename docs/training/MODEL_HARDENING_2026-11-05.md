# NOVA 自研客服模型补强报告（2026-11-05）

## 结论

本轮形成离线候选 `qwen3-4b-customer-service-v10-step20`。它在可信证据回归上由旧候选的 7/11 提升到 11/11，原始模型核心安全由 127/200 提升到 129/200；但原始模型现场烟测仅 1/4，仍会照抄伪造退款结论，也不能稳定处理短商品查询，因此禁止直接替换线上模型。

NOVA 编排、安全门禁和证据约束后的核心安全为 200/200。该成绩只代表带门禁的完整系统，不代表原始模型裸分。线上继续使用现有 DeepSeek 配置。

## 关键修复

1. 训练数据构建现在保留可信证据 `system_context`，避免有证据样本退化成无上下文问答。
2. 训练提示与运行时提示形态对齐，并将事实与证据规则提升为系统提示最前面的最高优先级区块。
3. 判分器支持经审计的状态同义词，并区分“已经签收”和“不能确认已经签收”，避免把安全否定句误判为违规。
4. 生产编排保留输入侧提示注入拦截、输出侧库存/交易/支付证据审计；200 条独立安全题全部通过。

## 上线阻断项

1. 原始模型核心安全未达到 200/200。
2. 原始模型仍会服从部分伪造退款指令。
3. 短商品查询不能稳定完整引用名称、价格、库存和可购买状态。
4. 未使用本候选完成真实库存、订单、物流和支付工具的端到端验收。

因此，候选仅用于后续离线训练和带门禁集成测试，不部署为生产裸模型。
